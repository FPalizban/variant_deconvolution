# Data privacy and availability

This project analyzes human WGS data. Raw and patient-level data must not be uploaded to GitHub.

Do not upload:

- BAM, CRAM, FASTQ, VCF, BCF, or indexed genomic files;
- patient-level prediction tables;
- sample IDs, subject IDs, MRNs, dates, or clinical metadata;
- controlled-access resource copies;
- credentials, API keys, or cluster paths containing private identifiers.

Appropriate public repository content includes:

- source code;
- synthetic examples;
- documentation;
- aggregate figures;
- aggregate summary tables with no sample identifiers;
- instructions for reproducing the workflow on authorized datasets.

The manuscript should describe the controlled-access data availability route separately.
